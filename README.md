# Johannes Brüstle — Academic Website

Academic website of Johannes Brüstle, Sapienza University of Rome. Research in algorithmic game theory, mechanism design, and online optimization.

Website: https://jbrustle01.github.io/

The site uses plain HTML, CSS, and JavaScript. GitHub Pages serves the `main` branch from the repository root. See [README.txt](README.txt) for file descriptions and editing instructions.

Light mode is the default. Visitors can switch between dark and light appearances in the header; their choice is remembered on their device across the website.

The former Teaching-page game is no longer displayed or loaded. Its source is preserved in [archive/game](archive/game/README.md), including the original page as non-rendered text. Shared game dependencies remain in `assets/`. The separate leaderboard backend and its data have not been changed.
